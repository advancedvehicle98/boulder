# Ценные указания

## Как собирать
Для установки недостающих модулей (DSDL, dronecan_dsdlc, cmocka):
```
git submodule update --init --recursive
# это нужно для dsdlc
pip install empy pexpect
```
Также предполагается, что имеются все необходимые кросскомпиляторы (вы вроде не маленькие уже, поэтому сообразите как поставить. Но хотя бы библиотеки для прошивок тянутся автоматом). Смотрите нужные префиксы в Kconfig (в частности, master/kconfig/Kconfig.toolchain и slave/kconfig/Kconfig.toolchain).

Предварительно нужно запустить menuconfig хотя бы один раз, для генерации .config и заголовков в generated/.

```bash
make menuconfig
```

После каждого `make clean` generated/ стирается, и нужно запускать menuconfig ещё раз, чтобы просто сохраниться и сгенерировать заголовки заново.

Собрать оба бинарника для master, и для slave, можно просто командой `make` (или `make all`).

Кроме того, есть следующие цели:
- `dsdl`: генерация файлов для интерпретации сообщений DroneCAN. Вызывается всегда с целью `all`;
- `clean`: очистка всех сгенерированных файлов (generated/ и out/);
- `clean-all`: цель `clean` и удаление загруженных архивов в modules/downloads/ и сгенерированных файлов при сборке git-модулей
- `flash`: (потом сделаю) прошивка ведомого устройства;
- `master`: сборка программы для ведущего устроства. Вызывается всегда с целью `all`;
- `rsync`: удалённая установка ведущей программы на одноплатник. Настроить адрес и путь установки можно через menuconfig;
- `slave`: сборка прошивки для ведомого устройства. Вызывается всегда с целью `all`;
- `tests`: (не доделано) запуск unit-тестов (в т.ч. предварительная сборка cmocka)

Для подробного вывода команд надо запускать make с `VERBOSE=1`
